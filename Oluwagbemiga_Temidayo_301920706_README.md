## 1. Project Overview

This repository contains my Advanced Database Systems portfolio, developed around a Hospital Management Information System (HMIS).

The case study explores how a hospital can use database technologies to manage patient information, doctors, appointments, diagnoses, prescriptions, and laboratory records.

The project demonstrates practical knowledge of relational database design, SQL querying, query optimisation, transaction management, NoSQL databases, and distributed database concepts.

The portfolio combines practical implementation, testing evidence, technical documentation, and analysis.

## 2. Portfolio Objectives

The main objectives are to:

- Design and implement a relational database for a hospital management system.
- Develop SQL queries to retrieve and manipulate hospital records.
- Analyse query execution plans and improve performance through indexing.
- Demonstrate transaction management, concurrency control, and data consistency.
- Explore NoSQL database modelling and operations using MongoDB.
- Investigate distributed database concepts, including replication, availability, failover, and cloud deployment considerations.

## 4. Portfolio Breakdown

### Portfolio 1: Database Design and Implementation

Focuses on designing and implementing the relational database for the hospital management system.

Key areas:
- Requirements and case study analysis.
- Entity Relationship Diagram (ERD).
- Relational schema and table relationships.
- Primary and foreign keys.
- Normalisation.
- SQL table creation and data manipulation.
- Testing and validation of database operations.


### Portfolio 2: Query Optimisation and Performance Analysis

Explores how SQL query performance can be analysed and improved.

Key areas:
- SQL queries and JOIN operations.
- Query execution plans using `EXPLAIN`.
- Index creation and evaluation.
- Before-and-after query performance analysis.
- Comparison of query execution plans.
- Performance optimisation findings.


### Portfolio 3: Transaction Management

Demonstrates how database transactions support reliable and consistent hospital operations.

Key areas:
- ACID properties.
- Transaction control using `COMMIT` and `ROLLBACK`.
- Transaction isolation.
- Concurrent database sessions.
- Locking and concurrency control.
- Practical transaction testing.


### Portfolio 4: NoSQL Database Implementation

Explores the use of MongoDB as a NoSQL alternative for managing selected hospital records.

Key areas:
- NoSQL database concepts.
- Document-oriented data modelling.
- MongoDB database and collection creation.
- CRUD operations.
- Querying and filtering documents.
- Aggregation operations.


### Portfolio 5: Distributed and Cloud Databases

Investigates distributed database concepts and demonstrates replication using a MongoDB replica set.

Key areas:
- Distributed database architecture.
- MongoDB replica set configuration.
- Primary and secondary nodes.
- Data replication.
- Secondary reads.
- Automatic failover and node recovery.
- Consistency and availability analysis.
- Sharding and cloud deployment considerations.
