# Portfolio 1: Database Design and Modelling

## Overview

This portfolio focuses on the design and modelling of a Hospital Management Information System (HMIS). The objective was to develop a relational database structure capable of managing essential hospital operations, including patient records, doctors, appointments, diagnoses, prescriptions, and laboratory investigations.

## Case Study

**Hospital Management Information System (HMIS)**

The system is designed to organize hospital information and maintain relationships between patients, doctors, appointments, diagnoses, prescriptions, and laboratory records.

## Database Environment

| Item | Description |
|---|---|
| Database Management System | MySQL / MariaDB |
| Database Name | hospital_management |
| Development Environment | XAMPP and phpMyAdmin |
| Storage Engine | InnoDB |
| Character Set | utf8mb4 |

## Database Tables

The database consists of seven relational tables:

1. `patients`
2. `doctors`
3. `appointments`
4. `diagnoses`
5. `prescriptions`
6. `laboratory_tests`
7. `laboratory_results`

## Design and Modelling Activities

The following activities were completed:

- Identified the major entities and attributes required by the HMIS.
- Designed the relational database schema.
- Established primary key and foreign key relationships.
- Applied database constraints to maintain data integrity.
- Normalized the database structure to reduce redundancy.
- Created an Entity Relationship Diagram (ERD).
- Implemented the schema using SQL.
- Inserted sample records and executed testing queries.

## Outcome

The portfolio produced a structured relational database for the HMIS, with clearly defined relationships and integrity constraints. The implementation provides the foundation for subsequent query optimization, transaction management, and other advanced database exercises.
